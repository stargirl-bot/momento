Momento

Momento is a personal bookmarking app where users can save, organize, and revisit URLs. Bookmarks are tagged and filterable for quick retrieval, and a built-in AI layer summarizes each URL's content automatically. Users can share curated bookmarks via email with a customizable subject line and body — pre-populated with the link and its AI summary.

Rails 8 React 19 Inertia.js PostgreSQL TypeScript Tailwind CSS v4 Solid Queue Vite 7

What the app does

  • Save & manage bookmarks

    Add URLs with an auto-fetched title, optional notes, and tags. Edit or delete any bookmark at any time.

  • Tag organization

    Create tags on the fly while saving a bookmark. Filter by one or more tags to narrow the list instantly.

  • Search & filter

    Live search across titles, URLs, notes, and AI summaries. Combine with tag filters for precise results.

  • AI content summarization

    When a bookmark is saved, Claude automatically fetches and summarizes the page in 2–4 sentences in the background.

  • Email sharing

    Share any bookmark by email. The compose form pre-fills with the link and AI summary; subject and body are fully editable before sending.

Out of scope (v1)

  • Browser extension — a "save to Momento" button in Chrome/Safari is a separate build effort
  • Public bookmark pages — sharing a public URL to your bookmark collection (email sharing is in)
  • Social / following — following other users' bookmark collections
  • Favorites / pinning — separate from tags; adds complexity for marginal v1 value
  • Trash / undo delete — soft deletes with recovery; v1 uses confirm-to-delete
  • Multiple AI providers or model selection — one provider (Anthropic), one model, no user-facing controls
  • Per-user AI API keys — app-level key only; users do not bring their own
  • Billing / paywalled tiers — all features free and unlocked in v1
  • Team / shared workspaces — bookmarks are personal only in v1
  • Native mobile app — web-only; responsive design but no iOS/Android app
  • Collections / Lists — named bookmark groups; tags handle organization in v1
  • Bookmark import — importing from a Chrome/Safari HTML export file
  • Share history — the app sends email but does not store a record of shares sent

External integrations

Anthropic (Claude API)

AI summarization

When a bookmark is saved, the app calls Claude to fetch and summarize the page's content. Runs in the background so users don't wait.

Credentials needed

  • Anthropic API key (from console.anthropic.com)

Resend

Email delivery

Handles delivery of share emails. Required because apps can't send email directly — a relay service handles deliverability. Free tier: 3,000 emails/month.

Credentials needed

  • Resend account + API key (from resend.com)
  • Verified sending domain

Milestones

1

Bookmarks + Search & Filter

Delivers the full bookmark management experience: saving, editing, deleting, tagging, tag management, live search, and filterable tag sidebar with shareable URL state.

What gets built

  • Bookmarks page as the logged-in home, listing all bookmarks newest-first
  • "+ New Bookmark" form with URL, auto-fetched title, notes, and tags field
  • URL paste triggers background title fetch; falls back to manual entry
  • Bookmark card showing title, URL/domain, notes, tags as pills, date saved
  • Edit (re-opens form) and Delete (with confirm step) actions per bookmark
  • Pagination or infinite scroll on the bookmark list
  • Tags created on the fly from the bookmark form with autocomplete
  • Sidebar (or top filter bar) with tag list and per-tag bookmark counts
  • Tag filter: click to filter, multi-tag AND logic, URL state updated for shareability
  • Tag Management page: rename and delete tags globally
  • Live search bar across title, URL, notes; composable with active tag filter

Not in this milestone

  • AI summarization (placeholder area on the card is fine, but no background job yet)
  • Email sharing
  • Search across AI summary text (no summaries exist yet)

Done when: A user can log in, add a bookmark by pasting a URL (title auto-fills), assign tags, search their bookmarks by text, filter by one or more tags, and manage tags — all in the browser with no console errors.

2

AI Summarization

Wires up the background summarization pipeline: Claude fetches and summarizes each bookmarked page, with a live placeholder, graceful failure states, and a manual regenerate option.

What gets built

  • Saving a bookmark enqueues a background job to fetch the page and ask Claude for a 2–4 sentence summary
  • Bookmark card shows "Summarizing…" placeholder until the job completes
  • Summary appears on next page load or refresh — no live push
  • "Summary unavailable" note shown when page is unreachable (404, paywall, blocked) or AI call fails
  • "Regenerate summary" button on each card lets the user re-trigger manually
  • Summary text is plain text — no markdown rendering, no embedded links
  • Search now also searches across AI summary text

Not in this milestone

  • Live summary updates without a page refresh
  • Summary length, tone, or style controls
  • Summarizing PDFs, videos, or non-HTML pages
  • AI-suggested tags
  • Email sharing

Done when: Saving a bookmark shows "Summarizing…" on the card; after a page refresh the summary appears in plain text. Saving a URL that can't be fetched shows "Summary unavailable." The "Regenerate" button re-runs the job successfully.

3

Email Sharing

Adds the ability to share any bookmark by email — with a compose form pre-filled with the link and AI summary, and a fully editable subject line and body before sending.

What gets built

  • "Share" button on each bookmark card
  • Compose form with: To (recipient email, required), Subject (pre-filled with bookmark title, editable), Body (pre-filled with URL + AI summary, editable)
  • One-shot "Send" action delivers the email via Resend
  • Recipient receives a plain, readable email with the link and summary

Not in this milestone

  • Multiple recipients in one send
  • CC / BCC fields
  • Scheduling sends for later
  • Email open / click tracking
  • Share history stored in the app
  • Sharing multiple bookmarks in one email
  • Rich HTML email templates with branding

Done when: Clicking "Share" on a bookmark opens a compose form pre-filled with the title and summary; editing subject and body and clicking "Send" delivers an email to the recipient's inbox.
